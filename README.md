# 🗺️ Web Development Roadmap 2027

A beginner-friendly, step-by-step roadmap to become a web developer. It covers the core front-end skills, a modern framework, and CMS development with WordPress, plus project ideas to build a portfolio that gets noticed.

> Maintained by the training team at [99eedu](https://99eedu.com/), an IT training institute in Kolkata, India. Contributions and suggestions are welcome.

---

## 📌 Who Is This For?

- Students and freshers starting a tech career
- Career switchers moving into web development
- Designers who want to learn to code
- Freelancers who want to offer website services

---

## 🧭 The Roadmap at a Glance

```
Internet Basics → HTML → CSS → Responsive Design → JavaScript
        → Git & GitHub → React → CMS (WordPress) → Portfolio → Job / Freelance
```

---

## ✅ Step 1: Understand How the Web Works

- [ ] What happens when you type a URL in a browser
- [ ] Client vs server
- [ ] What are domains, hosting, and DNS
- [ ] HTTP vs HTTPS
- [ ] How to use browser developer tools

---

## ✅ Step 2: HTML (Structure)

- [ ] Headings, paragraphs, lists, links, images
- [ ] Forms and input types
- [ ] Semantic tags (`header`, `nav`, `main`, `section`, `footer`)
- [ ] Accessibility basics (alt text, labels)
- [ ] SEO basics (title, meta description, heading order)

**Practice:** Build a one-page personal profile.

---

## ✅ Step 3: CSS (Style)

- [ ] Selectors, the box model, colors, typography
- [ ] Flexbox
- [ ] CSS Grid
- [ ] Positioning
- [ ] Transitions and simple animations

**Practice:** Recreate the layout of a website you like.

---

## ✅ Step 4: Responsive Design

- [ ] Mobile-first thinking
- [ ] Media queries
- [ ] Relative units (`%`, `rem`, `vw`)
- [ ] Responsive images
- [ ] Testing on multiple screen sizes

**Practice:** Make your Step 2 and 3 project work well on phone, tablet, and desktop.

---

## ✅ Step 5: JavaScript (Behavior)

- [ ] Variables, data types, operators
- [ ] Conditions and loops
- [ ] Functions and scope
- [ ] Arrays and objects
- [ ] DOM manipulation and events
- [ ] Async JavaScript: Promises, `async/await`, `fetch`
- [ ] ES6+ features

**Practice:** Build a to-do list, a calculator, and a weather app using a public API.

---

## ✅ Step 6: Git & GitHub

- [ ] `git init`, `add`, `commit`, `push`, `pull`
- [ ] Branching and merging
- [ ] Writing a clear README
- [ ] Hosting a project with GitHub Pages

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/your-username/your-repo.git
git push -u origin main
```

---

## ✅ Step 7: React

- [ ] Components and JSX
- [ ] Props and state
- [ ] Hooks (`useState`, `useEffect`)
- [ ] Conditional rendering and lists
- [ ] Routing
- [ ] Fetching and displaying API data

**Practice:** Rebuild your to-do or weather app in React.

---

## ✅ Step 8: WordPress & CMS Development

Many businesses run on WordPress, so this skill opens up freelance and agency work.

- [ ] Installing WordPress and choosing hosting
- [ ] Themes and page builders
- [ ] Plugins and when to use them
- [ ] Custom post types
- [ ] WooCommerce for online stores
- [ ] Basic security and speed optimization

**Practice:** Build a business website and a small online store.

## 💡 Tips for Learning Faster

1. **Build, don't just watch.** Code along, then rebuild from memory.
2. **Commit daily.** A visible contribution history shows consistency.
3. **Read other people's code.** Open-source projects teach a lot.
4. **Learn to debug.** Use the browser console and read error messages carefully.
5. **Write about what you learn.** Explaining a concept shows whether you understand it.
